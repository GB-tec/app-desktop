Formato esperado no arquivo .txt:
CNPJ_OU_CPF;NOME DA EMPRESA;INSCRIÇÃO ESTADUAL

Exemplos:
1º → 12.345.678/0001-90;EMPRESA LTDA;123456789
2º → 123.456.789-10;PRODUTOR RURAL LTDA;Isento
3º → 11.222.333/0001-44;TERCEIRA EMPRESA;987654321

* A Inscrição Estadual é opcional
* Use ponto e vírgula (;) para separar os campos
* Uma empresa/produtor por linha
* Aceita tanto CNPJ (14 dígitos) quanto CPF (11 dígitos)
